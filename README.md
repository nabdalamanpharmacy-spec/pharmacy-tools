# Pharmacy Tools Hub

A management hub for pharmacy operations.

## Tools

- **Milk Procurement** — Compare prices across sub-agents, generate split POs
- **Wasfaty Auto-Order** — Track Wasfaty consumption, auto-generate supplier POs

## Tech

- Pure HTML/CSS/JS — no build step
- Supabase (PostgreSQL) for data persistence
- Claude AI API for PDF parsing and item matching
- Hosted on GitHub Pages
